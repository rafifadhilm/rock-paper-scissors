# rock-paper-scissors

This is Rock Paper Scissors game project from **The Odin Project**. This game can play 5 rounds against the computer, and all outputs are displayed via the browser console.

Currently, the game expects valid inputs (rock, paper, or scissors) and does'nt have a "try again" feature to correct input errors. However, the `toLowerCase()` method has been implemented, so it can handles inputs regardless of uppercase or lowercase formatting.
